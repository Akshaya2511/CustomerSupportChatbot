# Customer Service Chatbot (Text + Voice)

A simple NLP-based customer service chatbot that can answer predefined questions using text or voice input.  
This is a beginner-friendly backend chatbot built with Python and TF-IDF similarity.

---

## 🚀 Features

- Predefined Q&A responses
- NLP-based similarity matching (TF-IDF + cosine similarity)
- Text chat support
- Voice input and voice output support
- Modular backend design (can connect to any frontend)

---

## 🧠 How It Works

1. User input (text or voice) is received  
2. Input is converted to text (for voice mode)  
3. TF-IDF vectorization compares input with stored questions  
4. Best matching answer is returned  
5. Voice mode also speaks the response
